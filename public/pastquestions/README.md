# Past Question PDFs

Drop the downloadable question-paper PDFs here. The file names must match the
`pdfUrl` set in `src/data/pastQuestions.js`, e.g.:

- `COS101-20232024.pdf`  → COS 101, 2023/2024
- `GES101-20232024.pdf`  → GES 101, 2023/2024

These are served from `/pastquestions/<file>.pdf`. The "Download the PDF" button
on each course's past-questions page fetches them. Until a file is added the
button will report that the PDF isn't available yet.
